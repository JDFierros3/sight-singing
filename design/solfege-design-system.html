Using this file

How to treat this document

This is the canonical UX reference. It lives in the repo at design/solfege-design-system.html and is published as an artifact for viewing. Future work — and future Claude sessions with fresh context — should read it as the source of truth for layout, component names, colours, and the mobile-vs-desktop split. When we implement, the CSS classes here (.sn, .sessbar, .card, .rail, .inspector, .quiz, .stave) become the real component vocabulary. If we later want a formally hosted design system, these same components can be pushed to a Claude Design project.

Schematic fidelity — real labels, real shape-notes, approximate spacing. Product screens use the app's dark palette in both document themes.
